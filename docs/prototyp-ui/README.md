# Poglądowy prototyp UI — Miara

Otwórz [index.html](index.html) w przeglądarce. Prototyp działa lokalnie bez instalacji i pokazuje pięć głównych ekranów oraz szczegóły przepisu. Koncepcja wizualna „Miara” traktuje plan i dziennik jak osobisty notes: kontrastowe kolory, typografia redakcyjna, karty przepisów przypominające fiszki i wartości odżywcze w układzie etykiety.

Można wyszukać przepis, obejrzeć przykładowy szacunek wartości odżywczych, dodać danie do planu, potwierdzić spożycie w dzienniku i zmienić cel lub alergeny w profilu. Dane są demonstracyjne i znikają po odświeżeniu strony. Prototyp nie wykonuje zapytań do stron z przepisami ani do bazy żywieniowej.

Źródło zakresu: [wymagania funkcjonalne i przypadki użycia](../wymagania_funkcjonalne_i_przypadki_uzycia.md).

Edytowalna makieta sześciu ekranów i przepływu nawigacji: [miara-prototyp.drawio](miara-prototyp.drawio).

Plik `.drawio` jest statyczną makietą; interakcje pozostają w `index.html`.
